# LoopMart v0.1 界面精修

> 本文记录第一轮精修。用户随后批准整体重设计，视觉方向以 [校园交换站设计](2026-11-14-loopmart-campus-exchange-design.md) 为准；本轮的功能修复和性能调整继续保留。

日期：2026-11-14。用户已确认：覆盖用户端与管理后台，沿用蓝色／灰绿色主题，保留业务功能与信息架构。

## 设计方向

采用现有系统字体、蓝色主操作、灰蓝页面和白色面板；后台保留灰绿色主操作、灰绿页面和紧凑表格。保留商品 4:3 媒体、左右筛选与网格、现有响应断点和圆角。通过字体层级、成组间距、对比度和清晰操作改善质量，不新增营销文案、装饰横幅或无依据的数据。

Frontend Design 与 UI UX Pro Max 用于确定层级和交互；Impeccable 用于检查一致性；Web Design Guidelines 用于检查键盘、焦点、表单和响应式；React Best Practices 用于定位可验证的首屏加载问题。技能是内部开发依据，不进入产品页面。

## 具体调整

- 用户端：统一导航和收藏的线性矢量图标，手机底栏保留五个入口；触摸区域至少 44 CSS px，输入字号至少 16px。
- 列表：移除重复排序文案；保留真实数据和排序；筛选无结果可直接清空；筛选错误后可恢复，加载反馈保留已存在内容。
- 键盘：保留并验证 Astryx 自带的跳至主内容入口和主区域；焦点可见，图标保留文字或可访问名称。
- 后台：改善表头、次级文字、标签和状态文字的对比度；不扩大桌面控件与表格密度，不改变权限和管理确认流程。
- 性能：保留市场即时加载，将账号、发布、聊天、后台等按需页面用 Next.js 动态导入拆包；保留 SSR 和骨架反馈。不修改实时消息、鉴权、缓存或 API 行为。
- 表单：丢弃草稿需确认，取消保留输入；认证字段提供准确的浏览器自动填充语义。账号总标题覆盖全部账号面板，后台列表只展示一个空状态。

## 范围与验收

仅修改共享 UI、主题、必要浏览器回归和开发文档；不新增依赖，不更改后端、数据库、部署或生产配置。使用当前 `v0.1-ui-improvement` 分支。

使用已有 API 拦截 fixture 验证中英文、桌面和手机页面；检查 320、390、768、1024、1440px 无整页溢出、焦点路径、筛选恢复和主要入口。运行现有单元测试、类型检查、主题同步检查、生产构建与 Astryx doctor；比较生产首屏 JS 产物，不将产物体积等同于真实用户加载时间。
