# LoopMart 首版验收记录

验收完成日期：2026-11-13；开发始于 2026-11-12。范围以已批准设计和后续用户授权为准。此记录描述本地实现与验证，不表示已经公网部署。

## 交付范围

已实现响应式用户 Web、Admin、独立 Better Auth、PostgreSQL 迁移、单社区资格、二手市场、拼车、发布编辑及本地文字草稿、商品收藏、个人资料与公开发布列表、按用户对合并的私聊、内容引用、分页补齐、实时更新、未读与已读、四类举报、社区管理员消息、联系表单、运行配置、双语隐私政策及敏感操作审计。

Admin 包括用户创建／角色／封禁／密码管理、商品与拼车增删改及审核、举报处理、会话查看、配置身份的社区消息、联系表单处理、完整适用筛选与审计前后快照。后台消息与实际操作人分别记录，通知失败持久重试。

首版保持无支付、不上传媒体、不开发 iOS。媒体类型与服务契约已经预留，无签名上传接口或无效入口。实际配置的 SMTP 留空，不开放验证绕过；真实发信需要后续配置。

## 已知边界

- 没有真实 SMTP 投递验收；SMTP 未配置时用户不能完成真实注册验证或找回密码。这是已批准的首版运行限制。
- 当前单 API 进程负责实时事件分发和内存限流，未承诺多实例一致性；未来横向扩容需增加跨实例事件和限流协调。
- 已建立的 SSE 连接每 20 秒重新检查资格，封禁／撤销后的流最多有该检查间隔的收敛时间；新请求立即重新验证。
- 只验证本地 Chromium 桌面和手机视口，未单独执行 Safari、真实 iPhone 或屏幕阅读器完整验收。
- 云端域名、TLS、生产 SMTP、备份保留周期、数据保留政策和具体上线变更在实际部署前另行审核。OCI 与 Cardmaster 没有被修改。

针对性浏览器脚本 `tests/browser/errors_and_rides.py` 额外验证真实登录错误与 SMTP 503 的双语显示、错误内部信息隐藏、地点／时区预设与自定义地点、实际拼车排序、时区时间及座位展示、公开详情字段筛选和同浏览器账号 A／B／A 草稿恢复与丢弃。
